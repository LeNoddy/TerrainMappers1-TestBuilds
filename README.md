# TerrainMappers1 -- Test Builds

This repo hosts test-build APK downloads for [TerrainMappers1](https://github.com/Flownriver/TerrainMappers1), an Android app that records a walk using your phone's sensors (accelerometer, gyroscope, gravity, magnetometer) and shows a breakdown of what you did -- standing/walking/jogging segments, turns with angle and direction, and nearby metal/concrete detected along the way.

This is **not** the source code repo -- just a place to publish downloadable test builds. See the [Releases](../../releases) page for the latest APK.
